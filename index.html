Dokumentasi Teknis Pengembangan Web

1. Git dan GitHub

Git adalah sistem kontrol versi terdistribusi untuk melacak setiap perubahan kode secara lokal melalui commit dan branch. GitHub berfungsi sebagai repositori jarak jauh (remote) untuk kolaborasi, pengelolaan Pull Request, penggabungan (merge), serta penyelesaian konflik kode.

2. npm, package.json, dan Semantic Versioning

npm mengelola paket pustaka melalui file package.json. dependencies berisi pustaka yang dibutuhkan saat aplikasi berjalan di produksi, sedangkan devDependencies hanya dipakai saat tahap pengembangan (seperti TypeScript dan Vite). Format Semantic Versioning (MAJOR.MINOR.PATCH, contoh ^5.6.2) mengatur kompatibilitas pembaruan paket secara otomatis.

3. TypeScript

TypeScript menambahkan sistem pengetikan statis (static typing) di atas JavaScript menggunakan tipe data primitif (string, number, boolean), Array, Interface, Type Alias, Union Type, dan Generics untuk mencegah bug sebelum kode dijalankan.

4. Vite serta Peran Compiler, Transpiler, dan Bundler

Vite mempercepat pengembangan web modern melalui tiga mekanisme utama: Transpiler (menggunakan esbuild untuk mengubah sintaks TypeScript menjadi JavaScript standar yang dipahami browser), Compiler (tsc memeriksa validitas tipe data sebelum proses build), dan Bundler (menggunakan Rollup saat perintah npm run build untuk menggabungkan dan meminimalkan seluruh modul aset ke dalam folder dist/).

5. Environment Variables

File .env menyimpan variabel konfigurasi lingkungan seperti nama dan versi aplikasi (VITE_APP_NAME, VITE_APP_VERSION). File .env dikecualikan melalui .gitignore agar kredensial rahasia tidak bocor ke GitHub, sementara .env.example disediakan sebagai panduan struktur variabel bagi pengembang lain.
